# 轻量级桌面日程管理软件（v1.3.0）

一个开箱即用的 Windows 桌面日程管理工具，**单文件 .exe**，双击即可运行，
无需安装 Python 或任何运行环境。

- 技术栈：Python 3 + tkinter + Pillow（仅背景图/图标需要，已打包）
- 数据存储：本地 JSON（人类可读，便于备份迁移）
- 目标系统：Windows 10 / 11；**应用自带图标**（用户提供的 `256x256.ico`）

**v1.3.0 新增**：① 单实例（托盘待机时再次双击 exe 只唤醒既有窗口，不重复建进程）；
② 托盘右键菜单定位修复；③ 背景图置于最上层（透明 PNG 露原背景）；④ 子窗口放大并随 DPI 缩放；
⑤ 打包使用自定义 ico；⑥ 周期日程（每天/每周/每月/工作日）并入「添加日程」；
⑦ 标记与置顶（🚩红旗自动置顶 / 自定义颜色标记 / 📌置顶，显示在备注之后，「标记完成」更名「完成」）；
⑧ 便签可打开 .txt/.md/.py；⑨ 符号小窗（Ctrl+G 或「Σ 符号」按钮，一键输入希腊字母/数学符号）。

## 一、使用说明

### 主界面：「今日 / 进行中」

| 操作 | 步骤 |
|---|---|
| **添加日程** | 「＋ 添加日程」：标题（必填）/ 备注 / 截止时间 / **周期**（不重复/每天/每周/每月/工作日）。快捷截止：今天 18:00 / 明天 09:00 / 下周一 / 下周末 / 月末；输入截止时间时实时显示「距…还有 N天N时N分」 |
| **周期日程** | 到期后自动推进到下一周期（不会变"已过期"）；「✓ 完成」当前周期后自动排入下一周期 |
| **修改日程** | 选中 → 「✎ 修改」（标题/备注/截止/周期） |
| **完成 / 作废** | 「✓ 完成」（周期任务=完成当前周期并推进）；「🚫 作废」 |
| **标记与置顶** | 「🚩 标记」→ 红旗（自动置顶）/ 自定义颜色… / 清除；「📌 置顶」开关。标记显示在备注之后（📌🚩 或 ●颜色） |
| **子日程** | 「＋ 子日程」添加子项（缩进显示、单层不可嵌套），子项可独立「✓ 子项完成/取消」 |
| **删除 / 详情** | 「🗑 删除」（二次确认）/ 双击查看详情（含周期/标记/子日程） |

**醒目提示**：🔴 红行=已过期；🟡 黄行=24h 内到期；「剩余时间」列实时显示 `3天4时25分 / 已过2天3时`，每 30 秒刷新；启动弹窗提醒。

**窗口**：默认 1180×760（DPI 缩放），拖动后自动记忆大小/位置。**单实例**：程序已在运行（含托盘待机）时再双击 exe，只唤醒既有窗口，不会重复启动。

### 历史视图

- 三类：✅ 已完成 / 🚫 作废 / ⏰ 已过期（自动归类，仅查看与彻底删除）
- 类别筛选 / 日期筛选（全部·今天·昨天·近7天·近30天·**30天以上**）/ **关键词搜索**（标题/备注，实时）
- 导出 CSV（Excel 可开）、详情

### 便签

- 多行编辑，自动保存到 `notes.txt`（关闭时也自动保存）
- 工具栏：**保存** / **📂 打开文件**（仅限 .txt/.md/.py）/ **另存为**（.txt/.md）/ **Σ 符号** / **清空全部内容**

### 符号小窗

- 任意输入框按 **Ctrl+G**（或点便签「Σ 符号」）召唤/关闭小窗，点希腊字母/数学符号即插入光标处
- 支持：αβγ…ω、大写希腊字母、≈≠≤≥±∓×÷∂∇∞∫∑∏∈∉∪∩→⇒←↑↓√²³°′″·…½⅓¼‰℃℉ 等

### 设置中心（⚙）

| 设置项 | 说明 |
|---|---|
| 深色模式 | 即时切换 |
| 背景图片 | ≤8MB 的 PNG/JPG/BMP/GIF/WEBP；**置于背景最上层**，含透明图层的 PNG 会露出原主题背景 |
| 开机自启动 | 写 HKCU Run（exe 需放在稳定路径） |
| 关闭时最小化到托盘 | 关闭=隐藏待机；双击托盘恢复，右键菜单显示/退出（菜单定位已修复） |
| 导出历史 CSV / 打开数据文件夹 | 数据操作 |

## 二、数据文件位置

| 文件 | 路径 |
|---|---|
| 日程 | 程序同目录 `schedule.json`（含 `repeat` 周期 / `pinned` 置顶 / `flag` 标记字段） |
| 设置 | 程序同目录 `settings.json`（窗口大小/主题/自启/托盘/背景） |
| 便签 | 程序同目录 `notes.txt` |
| 图标 | 打包附带 `256x256.ico`（任务栏/托盘图标） |

- 程序放哪数据就在哪（整体拷贝即迁移）；`--data-dir` 可覆盖；目录不可写时兜底 `%APPDATA%\DeepSeekSchedule`。
- 旧版数据自动补齐新字段（repeat/pinned/flag），无需迁移。

## 三、如何从源码运行

```bash
pip install pillow
python schedule_app.py                 # 正常启动
python schedule_app.py --data-dir DIR  # 便携模式
python schedule_app.py --selftest      # 逻辑自测（11 组，含周期/标记）
python schedule_app.py --smoke         # GUI 冒烟 + 托盘创建测试
```

## 四、如何自己打包 .exe

```bash
pip install pyinstaller pillow
pyinstaller --onefile --windowed --name 日程管理 --icon 256x256.ico \
  --add-data "256x256.ico;." schedule_app.py
```

> miniforge/conda 的 Python 需附带 tcl/tk 运行时（见 `日程管理.spec`）：
> `--add-binary "<conda>\Library\bin\tcl86t.dll;."`、`tk86t.dll`，
> `--add-data "<conda>\Library\lib\tcl8.6;tcl"`、`tk8.6;tk`。

产物：`dist\日程管理.exe`（约 28 MB）。
