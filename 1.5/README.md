# 轻量级桌面日程管理软件（v1.5.0）

一个开箱即用的 Windows 桌面日程管理工具，**单文件 .exe**，双击即可运行，
无需安装 Python 或任何运行环境。

- 技术栈：Python 3 + tkinter + Pillow（仅背景图/画板/图标需要，已打包）
- 数据存储：本地 JSON，统一存放于 `<程序目录>\data\` 子文件夹（人类可读，便于备份迁移）
- 目标系统：Windows 10 / 11；**应用自带图标**（`256x256.ico`）
- 体积上限：exe + 依赖 **< 100MB**（当前约 29MB）

**v1.5.0 更新**：
- 修复：半透明模式不再把背景一起变淡（背景图放在主窗口正后方的不透明背景窗口，完整不透明度透出）；
  开机自启动提权后真正生效（提权回调同时写 HKCU + HKLM 并回读校验）；
  全局符号/句子插入修复（SendInput 结构错误导致"光标处无输出"，已修正并实测送达）
- 新增：历史记录「📋 复制为模板」——复制历史日程为模板，修改日期后保存为新的常规日程
- 默认全局热键调整为 **Ctrl+Shift+G（符号）/ Ctrl+Shift+S（句子）**（Alt+Ctrl 常被输入法占用）

## 一、使用说明

### 主界面：「今日 / 进行中」

| 操作 | 步骤 |
|---|---|
| **添加日程** | 「＋ 添加日程」：标题/备注/**开始时间**/**截止时间**/**周期**。设开始时间即"事件"；开始/截止至少填一个；快捷截止今天/明天/下周一/下周末/月末 |
| **完成 / 作废 / 修改 / 删除** | 选中后操作（删除二次确认）；周期任务「完成」自动排入下一周期 |
| **标记与置顶** | 🚩红旗（自动置顶）/ 🎨自定义颜色 / 📌置顶，标记显示在备注之后 |
| **子日程** | 「＋ 子日程」（缩进、单层），子项独立完成/取消 |
| **详情** | 双击条目 |

**醒目提示**：🔴 红行=已过期；🟡 黄行=24h 内到期；剩余时间列实时显示 `3天4时25分 / 已过2天3时`；启动弹窗提醒。
**单实例**：已运行（含托盘）时再双击 exe 只唤醒既有窗口。

### 历史视图

- 三类：✅ 已完成 / 🚫 作废 / ⏰ 已过期；类别筛选 / 日期筛选（含 30天以上）/ 关键词搜索
- **📋 复制为模板**：以历史记录为模板复制一份（沿用标题/备注/周期/标记/置顶/子日程，时间清空），
  在弹出的对话框中修改日期后保存，即成为新的常规日程（历史记录保留）
- 彻底删除（二次确认）、导出 CSV、详情

### 便签

- 编辑器跟踪**当前文件**：默认 `data\notes.txt`；「📂 打开文件」（仅 .txt/.md/.py）后保存只写当前文件，
  默认便签不会被覆盖；启动自动加载上次打开的文件；「🏠 回到默认便签」返回前询问是否保存
- 保存/导出等提示为**非阻塞 toast**；「Σ 符号」「📋 句子」打开小窗

### 符号小窗 & 句子粘贴板（全局热键）

- **全局热键**（默认 符号 **Ctrl+Shift+G**、句子 **Ctrl+Shift+S**）：在**任何软件**中按热键唤起小窗，
  点击后自动把前台窗口还给原应用再输入，字符真正落在光标处
- 应用内：输入框按 `Ctrl+G` 直接召唤；点击直插光标处
- **可 DIY**：设置 →「符号 / 句子」页改热键、编辑符号列表（`data\symbols.json`）、恢复默认；
  句子存于 `data\snippets.json`

### 画板

- 24 色 + 橡皮（打洞露出底图）+ 粗细 + 清空全部；💾 存 PNG；🖼 打开图片作底图；⬜ 白板

### 设置中心（⚙）

| 设置项 | 说明 |
|---|---|
| 深色模式 / **半透明**（0.7~1.0） | 半透明时背景图保持完整不透明度，由面板透出（有背景时自动加强透出） |
| 背景图片 | ≤8MB；透明 PNG 露原主题背景 |
| 符号/句子全局热键 + 符号 DIY | 可改热键、编辑符号列表 |
| 开机自启动 | 普通 HKCU 写入；失败自动以管理员权限（UAC）重试，提权回调写 HKCU+HKLM 并校验 |
| 关闭时最小化到托盘 | 托盘双击恢复、右键菜单显示/退出 |
| 导出 CSV / 打开数据文件夹 | 数据操作 |

## 二、数据文件位置（统一 data/ 子文件夹）

| 文件 | 路径 |
|---|---|
| 日程 / 设置 / 便签 / 符号 / 句子 / 背景图 | `<程序目录>\data\` 下的 `schedule.json` / `settings.json` / `notes.txt` / `symbols.json` / `snippets.json` / `background.png` |
| 图标 | 打包附带 `256x256.ico` |

- 首次运行自动创建 `data\`；旧版散落文件自动迁移；`--data-dir DIR` 可指定其它目录
- 关闭后可直接编辑 JSON；损坏自动备份 `.bak`；旧版数据自动补齐新字段

## 三、如何从源码运行

```bash
pip install pillow
python schedule_app.py                 # 正常启动
python schedule_app.py --data-dir DIR  # 便携模式
python schedule_app.py --selftest      # 逻辑自测（11 组）
python schedule_app.py --smoke         # GUI 冒烟 + 托盘/热键测试
```

---

## 四、如何自己打包 .exe

```bash
pip install pyinstaller pillow
pyinstaller --onefile --windowed --name 日程管理 --icon 256x256.ico \
  --add-data "256x256.ico;." schedule_app.py
```

> miniforge/conda 的 Python 需附带 tcl/tk 运行时（见 `日程管理.spec`）：
> `--add-binary "<conda>\Library\bin\tcl86t.dll;."`、`tk86t.dll`，
> `--add-data "<conda>\Library\lib\tcl8.6;tcl"`、`tk8.6;tk`。

产物：`dist\日程管理.exe`（约 29 MB，上限 100MB 以内）。
