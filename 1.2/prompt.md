一、任务目标

开发一个轻量级桌面日程管理软件，并打包为单个可执行文件（.exe），要求开箱即用、无需用户安装额外运行环境。

二、核心功能需求
日程管理
支持添加日程：包含标题（必填）、备注（可选）、截止日期/时间（可选）
支持划去/完成日程：一键标记完成，视觉上划线或置灰
支持删除日程（可选，防止误操作可加二次确认）
数据持久化
所有数据保存为本地 JSON 文件（人类可读、便于备份迁移）
程序关闭后重新打开，数据不丢失
JSON 文件建议存放于用户目录（如 %APPDATA% 或程序同级目录），避免权限问题
历史记录
历史视图涵盖以下三类：
✅ 已完成（用户主动划去的）
🚫 已划线/作废（用户标记取消的）
⏰ 已过期（超过截止时间但未完成的，自动归入历史）
支持按日期筛选 / 时间线浏览
历史记录不可随意篡改，仅支持查看和彻底删除
界面要求
简洁直观，分「今日/进行中」和「历史」两个主视图
当日即将到期的事项有醒目标识（如高亮/颜色变化）
三、技术约束
技术栈：由你（Agent）自主选择，遵循以下原则：
优先保证打包后体积小、启动快
打包工具推荐使用 PyInstaller（单文件模式 --onefile）
最终交付物：一个 .exe 文件​ + 必要的说明文档（README）
数据存储：使用 JSON 格式
运行环境：目标用户为 Windows 10/11
四、交付要求
完整的源代码（结构清晰、有注释）
打包好的 .exe 文件（单文件，双击即可运行）
README.md，包含：
使用说明（添加/划去/查看历史的操作步骤）
JSON 数据文件路径说明（方便用户备份）
如需手动放置 JSON 或使用说明
五、验收标准
[ ] 双击 exe 可正常启动，无控制台报错
[ ] 添加日程后关闭程序再打开，数据仍在
[ ] 划去日程后，该条目出现在历史记录中
[ ] 过期未完成的日程自动归入历史
[ ] 历史视图可正常查看上述三类记录
[ ] 整个 exe + 依赖体积控制在合理范围（建议 < 50MB）
六、可选增强（如有余力）
系统托盘最小化
到期弹窗提醒
深色/浅色主题切换
数据导出（如导出历史为 CSV）
