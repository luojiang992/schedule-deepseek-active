# 轻量级桌面日程管理软件（v1.2.0）

一个开箱即用的 Windows 桌面日程管理工具，**单文件 .exe**，双击即可运行，
无需安装 Python 或任何运行环境。

- 技术栈：Python 3 + tkinter + Pillow（仅背景图功能需要，已打包）
- 数据存储：本地 JSON（人类可读，便于备份迁移）
- 目标系统：Windows 10 / 11

**v1.2.0 新增**：① 窗口默认更大并记忆上次大小/位置；② 历史日期筛选新增「30天以上」；
③ 历史关键词搜索；④ 快捷便签（保存/另存为 .txt/.md/清空）；⑤ 设置中心（⚙）；
⑥ 开机自启动 + 关闭时隐藏到托盘待机；⑦ DIY 背景图片。

## 一、使用说明

### 主界面：「今日 / 进行中」

| 操作 | 步骤 |
|---|---|
| **添加日程** | 「＋ 添加日程」→ 标题（必填）/ 备注 / 截止时间（可选，格式 `2026-08-30 18:00`） |
| **修改日程** | 选中进行中/已过期日程 → 「✎ 修改」 |
| **标记完成 / 作废** | 选中日程 → 「✓ 标记完成」或「🚫 标记作废」（完成时子日程一并完成） |
| **删除** | 「🗑 删除」（二次确认；删除父日程连同子日程） |
| **子日程** | 选中父日程 → 「＋ 子日程」添加多个子项；子项缩进显示，可独立「✓ 子项完成/取消」；单层不可嵌套 |
| **查看详情** | 双击条目（含子日程清单） |

**醒目提示与倒计时**：
- 🔴 红色行 = 已过期；🟡 黄色行 = 未来 24h 内到期
- 「剩余时间」列实时显示 `3天4时25分 / 2时10分 / 不足1分`，已过期显示 `已过2天3时`，每 30 秒自动刷新
- 启动时如有已过期/今日到期事项会弹窗提醒

**窗口大小**：默认窗口更大；拖动窗口大小/位置后会自动记忆（存于 `settings.json`），下次启动恢复。

### 历史视图

- 三类记录：✅ 已完成 / 🚫 作废 / ⏰ 已过期（自动归类，不可随意篡改，仅查看和彻底删除）
- **类别筛选**：全部 / 已完成 / 作废 / 已过期
- **日期筛选**：全部 / 今天 / 昨天 / 近7天 / 近30天 / **30天以上**（按记录日期倒序时间线浏览）
- **关键词搜索**：在「搜索」框输入关键词，按标题/备注实时过滤（忽略大小写）
- 工具栏：彻底删除（二次确认）、导出 CSV（Excel 可直接打开）、详情

### 便签（📝 第三个标签页）

- 随时输入，内容保存在数据目录的 `notes.txt`
- 工具栏：**保存**（写回 notes.txt）、**另存为**（可选择 `.txt` / `.md`）、**清空全部内容**（二次确认）
- 关闭程序时自动保存

### 设置中心（⚙ 设置）

| 设置项 | 说明 |
|---|---|
| 深色模式 | 勾选即时切换（也可随时再关） |
| 背景图片 | 「选择图片…」上传 ≤8MB 的 PNG/JPG/BMP/GIF/WEBP 作为窗口背景（显示在窗口边缘/空白区域，列表区保持主题色）；「移除背景」恢复 |
| 开机自启动 | 写入 `HKCU\...\Run`，开机自动启动（需程序位于稳定路径） |
| 关闭时最小化到托盘 | 勾选后点关闭按钮隐藏到系统托盘待机；双击托盘图标恢复窗口，右键托盘菜单可「显示主窗口 / 退出」 |
| 导出历史为 CSV | 一键导出全部历史记录 |
| 打开数据文件夹 | 直达数据目录，方便备份 |

> 托盘图标为纯 ctypes 调用系统 `Shell_NotifyIcon` 实现，无第三方依赖。

## 二、数据文件位置

| 文件 | 路径 |
|---|---|
| 日程 | 程序同目录 `schedule.json` |
| 设置 | 程序同目录 `settings.json`（窗口大小/主题/自启/托盘/背景） |
| 便签 | 程序同目录 `notes.txt` |

- 程序放在哪个文件夹，数据就在哪个文件夹（整体拷贝即迁移）；`--data-dir` 可指定其它目录；
  程序目录不可写时兜底到 `%APPDATA%\DeepSeekSchedule`。
- 关闭程序后可直接用记事本编辑 JSON；文件损坏会自动备份为 `.bak` 并重新开始，不崩溃。

### JSON 示例

```json
[
  {
    "id": "23f65c8e...", "title": "提交周报", "note": "周五下班前",
    "deadline": "2026-08-30 18:00", "created_at": "2026-08-29T02:16",
    "status": "active", "completed_at": null, "cancelled_at": null,
    "children": [ { "id": "ab12...", "title": "整理数据", "done": false, "created_at": "..." } ]
  }
]
```

## 三、如何从源码运行

```bash
# 需要 Python 3.10+（tkinter 内置）；背景图功能需要 Pillow
pip install pillow
python schedule_app.py

python schedule_app.py --data-dir D:\schedule-data   # 便携模式
python schedule_app.py --selftest                    # 逻辑自测（11 组，不开界面）
python schedule_app.py --smoke                       # GUI 冒烟 + 托盘创建测试
```

## 四、如何自己打包 .exe

```bash
pip install pyinstaller pillow
pyinstaller --onefile --windowed --name 日程管理 schedule_app.py
```

> 若使用 miniforge/conda 的 Python，tkinter 的 tcl/tk 运行时需显式附带（见 `日程管理.spec`）：
> `--add-binary "<conda>\Library\bin\tcl86t.dll;."`、`tk86t.dll`，
> `--add-data "<conda>\Library\lib\tcl8.6;tcl"`、`tk8.6;tk`。

产物：`dist\日程管理.exe`（约 28 MB，Pillow 打包所致；仍在 50 MB 以内）。
