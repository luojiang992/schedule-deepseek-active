# 轻量级桌面日程管理软件（v1.1.0）

一个开箱即用的 Windows 桌面日程管理工具，**单文件 .exe**，双击即可运行，
无需安装 Python 或任何运行环境。

- 技术栈：Python 3 + tkinter（仅标准库，无第三方依赖）
- 数据存储：本地 JSON（人类可读，便于备份迁移）
- 目标系统：Windows 10 / 11

**v1.1.0 更新**：① 剩余时间倒计时（日/时/分）；② 数据文件改存程序所在目录；
③ 进行中/已过期日程支持修改；④ 启用 Windows 高 DPI 感知（高分屏不再模糊）；
⑤ 新增单层子日程功能。

## 一、使用说明

### 主界面：「今日 / 进行中」

| 操作 | 步骤 |
|---|---|
| **添加日程** | 点击「＋ 添加日程」，填写标题（必填）、备注（可选）、截止时间（可选，格式 `2026-08-30 18:00`），点「保存」 |
| **修改日程** | 选中一条**进行中或已过期**的日程 → 点「✎ 修改」→ 修改标题/备注/截止时间后保存 |
| **标记完成** | 选中日程 → 「✓ 标记完成」（其子日程一并标记完成）→ 移入历史「✅ 已完成」 |
| **标记作废** | 选中日程 → 「🚫 标记作废」→ 移入历史「🚫 作废」 |
| **删除** | 选中日程 → 「🗑 删除」（二次确认；删除父日程会连同其子日程） |
| **子日程** | 选中一个父日程 → 「＋ 子日程」可为其添加多个子项；子项在父日程下缩进显示，选中子项点「✓ 子项完成/取消」独立勾选。子日程为**单层结构，不可再嵌套** |
| **查看详情** | 双击条目查看全部字段（含子日程清单） |

**醒目提示与倒计时**：
- 🔴 **红色行** = 已过期；🟡 **黄色行** = 未来 24 小时内到期
- 「剩余时间」列实时显示距截止的时长，如 **3天4时25分 / 2时10分 / 不足1分**，
  已过期显示 **已过2天3时**；每 30 秒自动刷新
- 程序启动时若有已过期或今日到期事项会弹窗提醒

### 历史视图

历史记录分三类，**自动归类、不可随意篡改**（仅查看和彻底删除）：

- ✅ **已完成**（记录日期 = 完成时间）
- 🚫 **已划线 / 作废**（记录日期 = 作废时间）
- ⏰ **已过期**（记录日期 = 截止时间）

工具栏支持：类别筛选（全部/已完成/作废/已过期）、日期筛选（全部/今天/昨天/近7天/近30天，
按记录日期倒序时间线浏览）、彻底删除（二次确认）、导出 CSV（Excel 可直接打开）。

### 其他

- 右上角「🌙 深色 / ☀️ 浅色」主题切换。
- 已启用 **DPI 感知**：在 125%/150% 缩放的显示器上文字清晰不模糊。

## 二、JSON 数据文件位置

| 场景 | 路径 |
|---|---|
| **默认（v1.1.0）** | **与程序同一目录**：exe 放在哪个文件夹，数据就在哪个文件夹（`<程序目录>\schedule.json`），方便整体拷贝迁移 |
| 便携模式 | `schedule_app.py --data-dir D:\某目录`（数据存到指定目录） |
| 兜底 | 若程序目录不可写（如被放在 `Program Files`），自动退回 `%APPDATA%\DeepSeekSchedule\schedule.json` |

> 说明：双击 `日程管理.exe` 后，第一次添加日程即会在 exe 旁边生成 `schedule.json`。

### JSON 格式示例

```json
[
  {
    "id": "23f65c8e86444ffeb75663e3c2503c4f",
    "title": "提交周报",
    "note": "周五下班前",
    "deadline": "2026-08-30 18:00",
    "created_at": "2026-08-29T02:16",
    "status": "active",
    "completed_at": null,
    "cancelled_at": null,
    "children": [
      { "id": "ab12cd34...", "title": "整理数据", "done": false, "created_at": "2026-08-29T02:17" }
    ]
  }
]
```

字段说明：

| 字段 | 含义 |
|---|---|
| `id` | 唯一标识（UUID） |
| `title` / `note` | 标题（必填）/ 备注（可选） |
| `deadline` | 截止时间 `YYYY-MM-DD HH:MM` 或空 |
| `created_at` | 创建时间（ISO） |
| `status` | `active` 进行中 / `done` 已完成 / `cancelled` 作废 |
| `completed_at` / `cancelled_at` | 完成 / 作废时间（对应状态才有值） |
| `children` | 子日程数组（单层），每项含 `id`/`title`/`done`/`created_at` |

> 旧版数据（无 `children` 字段）打开时会自动补齐，无需手动迁移。

### 备份与迁移

- **备份**：复制 exe 所在文件夹里的 `schedule.json` 即可；程序关闭状态下可直接用记事本编辑。
- **迁移**：把 exe 和 `schedule.json` 一起拷到别的电脑/文件夹，双击即用。
- 文件损坏时程序会把损坏文件改名保存为 `schedule.json.bak` 并重新开始，不会崩溃。

## 三、如何从源码运行

```bash
# 需要 Python 3.10+（自带 tkinter，无需安装任何第三方包）
python schedule_app.py

# 便携模式（数据存到指定目录）
python schedule_app.py --data-dir D:\schedule-data

# 逻辑自测（不开界面，含倒计时/子日程/数据目录等）
python schedule_app.py --selftest

# GUI 冒烟测试（构建界面后自动关闭）
python schedule_app.py --smoke
```

## 四、如何自己打包 .exe

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name 日程管理 schedule_app.py
```

> 若使用 miniforge/conda 的 Python，tkinter 的 tcl/tk 运行时可能不会自动打包，
> 需要显式附带（本仓库 `日程管理.spec` 已配置好）：
> `--add-binary "<conda>\Library\bin\tcl86t.dll;."`、`tk86t.dll`，
> 以及 `--add-data "<conda>\Library\lib\tcl8.6;tcl"`、`tk8.6;tk`。

生成的可执行文件位于 `dist\日程管理.exe`，体积约 10 MB。
