# 轻量级桌面日程管理软件

一个开箱即用的 Windows 桌面日程管理工具，**单文件 .exe**，双击即可运行，
无需安装 Python 或任何运行环境。

- 技术栈：Python 3 + tkinter（仅标准库，无第三方依赖）
- 数据存储：本地 JSON（人类可读，便于备份迁移）
- 目标系统：Windows 10 / 11

---

## 一、使用说明

### 主界面：「今日 / 进行中」

| 操作 | 步骤 |
|---|---|
| **添加日程** | 点击工具栏「＋ 添加日程」，填写标题（必填）、备注（可选）、截止时间（可选，格式 `2026-08-30 18:00`，留空则无截止），点「保存」 |
| **标记完成** | 选中列表中的日程 → 点击「✓ 标记完成」→ 确认。条目自动移入历史「✅ 已完成」 |
| **标记作废** | 选中日程 → 点击「🚫 标记作废」→ 确认。条目自动移入历史「🚫 作废」 |
| **删除** | 选中日程 → 点击「🗑 删除」→ 二次确认后彻底删除（不可恢复） |
| **查看详情** | 双击列表中的任意条目，可查看标题/备注/截止/创建/完成时间等全部字段 |

**醒目提示**：
- 🟡 **黄色行** = 未来 24 小时内到期（即将到期）
- 🔴 **红色行** = 已超过截止时间但仍未完成（已过期，仍显示在此视图方便你处理）

程序启动时若存在已过期或今日到期的事项，会弹窗提醒。

### 历史视图

历史记录分三类，**自动归类、不可随意篡改**（仅支持查看与彻底删除）：

- ✅ **已完成** —— 用户主动划去完成的事项（记录日期 = 完成时间）
- 🚫 **已划线 / 作废** —— 用户标记取消的事项（记录日期 = 作废时间）
- ⏰ **已过期** —— 超过截止时间但未完成的事项（记录日期 = 截止时间）

工具栏支持：
- **类别筛选**：全部 / 已完成 / 作废 / 已过期
- **日期筛选**：全部 / 今天 / 昨天 / 近 7 天 / 近 30 天（时间线浏览，按记录日期倒序排列）
- **彻底删除**：选中历史记录后删除（二次确认，不可恢复）
- **导出 CSV**：把当前全部历史记录导出为 CSV（UTF-8 带 BOM，Excel 可直接打开）

### 其他

- 右上角「🌙 深色 / ☀️ 浅色」可切换主题。
- 列表有变更时点「⟳ 刷新」即可重读数据文件（比如你手动编辑了 JSON）。

## 二、JSON 数据文件位置

| 场景 | 路径 |
|---|---|
| 默认 | `%APPDATA%\DeepSeekSchedule\schedule.json`（即 `C:\Users\<用户名>\AppData\Roaming\DeepSeekSchedule\schedule.json`） |
| 便携模式 | `schedule_app.py --data-dir D:\某目录`（数据存到指定目录，便于随身携带） |

> 提示：在 Windows 资源管理器地址栏输入 `%APPDATA%\DeepSeekSchedule` 回车即可直达数据目录。

### JSON 格式示例

```json
[
  {
    "id": "23f65c8e86444ffeb75663e3c2503c4f",
    "title": "提交周报",
    "note": "周五下班前",
    "deadline": "2026-08-30 18:00",
    "created_at": "2026-08-29T02:16",
    "status": "active",
    "completed_at": null,
    "cancelled_at": null
  }
]
```

字段说明：

| 字段 | 含义 |
|---|---|
| `id` | 唯一标识（UUID） |
| `title` | 标题（必填） |
| `note` | 备注（可选） |
| `deadline` | 截止日期时间 `YYYY-MM-DD HH:MM` 或空 |
| `created_at` | 创建时间（ISO） |
| `status` | `active` 进行中 / `done` 已完成 / `cancelled` 作废 |
| `completed_at` | 完成时间（仅 done 有值） |
| `cancelled_at` | 作废时间（仅 cancelled 有值） |

### 备份与迁移

- **备份**：关闭程序后，复制整个 `DeepSeekSchedule` 目录（或仅 `schedule.json`）即可。
- **恢复**：把备份的 `schedule.json` 放回原目录（或直接修改内容），重新打开程序即生效。
- **手动编辑**：程序关闭状态下可直接用记事本编辑 JSON（保持上面的格式即可）。
  文件损坏时程序会自动把损坏文件改名保存为 `schedule.json.bak` 并重新开始，不会崩溃。

## 三、如何从源码运行

```bash
# 需要 Python 3.10+（自带 tkinter，无需安装任何第三方包）
python schedule_app.py

# 便携模式（数据存到指定目录）
python schedule_app.py --data-dir D:\schedule-data

# 逻辑自测（不开界面）
python schedule_app.py --selftest

# GUI 冒烟测试（构建界面后自动关闭）
python schedule_app.py --smoke
```

## 四、如何自己打包 .exe

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name 日程管理 schedule_app.py
```

生成的可执行文件位于 `dist\日程管理.exe`，双击即可运行。
（打包体积约 8–10 MB，远小于 50 MB 上限。）
