# 轻量级桌面日程管理软件（v1.4.0）

一个开箱即用的 Windows 桌面日程管理工具，**单文件 .exe**，双击即可运行，
无需安装 Python 或任何运行环境。

- 技术栈：Python 3 + tkinter + Pillow（仅背景图/画板/图标需要，已打包）
- 数据存储：本地 JSON，统一存放于 `<程序目录>\data\` 子文件夹（人类可读，便于备份迁移）
- 目标系统：Windows 10 / 11；**应用自带图标**（`256x256.ico`）
- 体积上限：exe + 依赖 **< 100MB**（当前约 29MB）

**v1.4.0 变更**：
- 修复：便签打开其他文件不再覆盖默认便签（编辑器跟踪"当前文件"，保存只写当前文件）
- 新增：符号小窗可 DIY（自定义符号列表 + 全局热键，其他软件中也能唤起输入）；
  快捷句子粘贴板（全局热键 + JSON 存储）；便签缓存上次打开文件 + 「回到默认便签」；
  事件功能（开始/截止日期，可留空但不能同时留空）；画板（24 色/橡皮/清空/存 PNG/图片做底图）
- 优化：GUI 半透明（0.7~1.0 可调）；保存等提示改为非阻塞 toast；开机自启动失败自动请求
  管理员权限（UAC）；数据文件统一放入 `data/` 子文件夹（旧文件自动迁移）

## 一、使用说明

### 主界面：「今日 / 进行中」

| 操作 | 步骤 |
|---|---|
| **添加日程** | 「＋ 添加日程」：标题（必填）/ 备注 / **开始时间** / **截止时间** / **周期**。设置开始时间即为「事件」；开始/截止至少填一个（都留空=普通无时间日程）；快捷截止：今天/明天/下周一/下周末/月末，输入时实时显示"距截止还有…" |
| **事件** | 拥有开始~截止时间段的特殊日程，列表"开始 ~ 截止"列显示；开始不得晚于截止 |
| **周期日程** | 每天/每周/每月/工作日；到期自动推进下一周期；「✓ 完成」后自动排入下一周期 |
| **完成 / 作废 / 修改 / 删除** | 选中后操作（删除有二次确认） |
| **标记与置顶** | 🚩红旗（自动置顶）/ 🎨自定义颜色 / 📌置顶，标记显示在备注之后 |
| **子日程** | 「＋ 子日程」（缩进显示、单层），子项可独立完成/取消 |
| **详情** | 双击条目（含事件时间/周期/标记/子日程） |

**醒目提示**：🔴 红行=已过期；🟡 黄行=24h 内到期；剩余时间列实时显示 `3天4时25分 / 已过2天3时`，每 30 秒刷新；启动弹窗提醒。

**单实例**：程序已在运行（含托盘待机）时再双击 exe，只唤醒既有窗口，不会重复启动。

### 历史视图

- 三类：✅ 已完成 / 🚫 作废 / ⏰ 已过期；类别筛选 / 日期筛选（含 **30天以上**）/ 关键词搜索
- 彻底删除（二次确认）、导出 CSV、详情

### 便签

- 编辑器跟踪**当前文件**：默认 `data\notes.txt`；「📂 打开文件」（仅 .txt/.md/.py）后切到该文件，
  **保存/自动保存只写当前文件**，默认便签不会被覆盖
- 启动时自动加载上次打开的文件；「🏠 回到默认便签」返回前询问是否保存当前内容
- 保存/打开/导出成功均为**非阻塞 toast 提示**（右下角自动消失），不再强制点确认
- 「Σ 符号」按钮打开符号小窗；「📋 句子」打开快捷句子粘贴板

### 符号小窗 & 句子粘贴板（全局热键）

- **全局热键**（默认 符号 `Ctrl+Alt+G`、句子 `Ctrl+Alt+S`）：在**任何软件**中按热键即可唤起小窗，
  点击符号/句子会向当时有焦点的窗口输入（SendInput），无需先切回本程序
- 应用内也可用：便签等输入框按 `Ctrl+G` 直接召唤，点击直接插入光标处
- **可 DIY**：设置 →「符号 / 句子」页可改热键、编辑符号列表（每行一组字符，存于
  `data\symbols.json`）、恢复默认；句子存于 `data\snippets.json`，小窗内可添加/删除

### 画板（第四个标签页）

- 24 种颜色 + 橡皮 + 粗细（细/中/粗）+ 清空全部（二次确认）
- 💾 保存 PNG；🖼 打开图片作为画板底图在其上绘制；⬜ 白板恢复空白
- 橡皮会"打洞"露出底图（含图片底图），保存时按可见效果输出 PNG

### 设置中心（⚙）

| 设置项 | 说明 |
|---|---|
| 深色模式 | 即时切换 |
| **半透明** | 滑块调节 0.7~1.0，配合背景图增强可见性 |
| 背景图片 | ≤8MB；置于背景最上层，透明 PNG 露原主题背景 |
| 符号/句子热键 | 全局热键预设 + 符号列表 DIY |
| 开机自启动 | 写入失败时自动以管理员身份（UAC）重试 |
| 关闭时最小化到托盘 | 关闭=隐藏待机；托盘双击恢复、右键菜单显示/退出 |
| 导出 CSV / 打开数据文件夹 | 数据操作 |

## 二、数据文件位置（统一 data/ 子文件夹）

| 文件 | 路径 |
|---|---|
| 日程 | `<程序目录>\data\schedule.json` |
| 设置 | `<程序目录>\data\settings.json`（窗口/主题/半透明/热键/托盘/背景/便签记忆） |
| 便签 | `<程序目录>\data\notes.txt` |
| 符号列表 | `<程序目录>\data\symbols.json` |
| 句子 | `<程序目录>\data\snippets.json` |
| 背景图 | `<程序目录>\data\background.png` |
| 图标 | 打包附带 `256x256.ico` |

- 程序放哪数据就在哪（整体拷贝即迁移）；首次运行自动创建 `data\` 子文件夹；
  **旧版散落在程序目录的数据文件会自动迁移进 `data\`**；`--data-dir DIR` 可指定其它目录
- 关闭程序后可直接编辑 JSON；文件损坏自动备份为 `.bak` 不崩溃；旧版数据自动补齐新字段

## 三、如何从源码运行

```bash
pip install pillow
python schedule_app.py                 # 正常启动
python schedule_app.py --data-dir DIR  # 便携模式
python schedule_app.py --selftest      # 逻辑自测（10 组）
python schedule_app.py --smoke         # GUI 冒烟 + 托盘/热键测试
```

## 四、如何自己打包 .exe

```bash
pip install pyinstaller pillow
pyinstaller --onefile --windowed --name 日程管理 --icon 256x256.ico \
  --add-data "256x256.ico;." schedule_app.py
```

> miniforge/conda 的 Python 需附带 tcl/tk 运行时（见 `日程管理.spec`）：
> `--add-binary "<conda>\Library\bin\tcl86t.dll;."`、`tk86t.dll`，
> `--add-data "<conda>\Library\lib\tcl8.6;tcl"`、`tk8.6;tk`。

产物：`dist\日程管理.exe`（约 29 MB，上限 100MB 以内）。
